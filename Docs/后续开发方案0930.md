## 〇-Z2、0923 下午：门标签朝向/招牌去重/小字不可读

- 门标签改为固定朝向（不再广告牌旋转）：按门所在墙面朝向区域内侧挑出并固定旋转（南墙内门朝北、东西墙互相对应），距离淡入保留。
- 酒吧门去掉与招牌重复的门标签（有"酒吧"招牌的门直接用招牌，CreateDoor 加 skipLabel 参数）。
- **牌子小字不可读的根因**：TMP 无 Canvas 的世界文字必须用"小 rect + 大缩放"（门标签的约定）；之前 AddBoardText 用"大 rect + 小缩放"，TMP 实际渲染尺寸会异常缩小到几乎不可见。已统一改为按文字长度计算小 rect，并按场景分级缩放（门牌 0.40 / 菜单 0.45 / 墙面招牌 0.55 / 楼顶广告 1.2）。酒吧招牌文字同时改为高对比金色、只留中文"酒吧"（拉丁小字在该字体下渲染不可靠）。
- 实机截图验证：酒吧招牌、"营业中"、"樱花町 X 号"门牌、室内出门标签（回到街道）与室外进门标签（进入：死者公寓）全部可读。
