# 当前版本通关攻略

更新：2026-09-24，密码/全文/教学/终章人物整合版。含全部结局剧透。

本攻略按当前项目代码、对白数据与配方整理。推荐路线不使用Debug发放物品，可保留A/B/C/D四个结局的选择资格；一局最终只能选择一个。不是“单周目收齐全部线索”的路线，因为部分对白奖励互斥。此前攻略中的备用钥匙、保险箱直接领取、旧关系数值和旧结局数量门槛均已作废。

## 先记住这些操作

| 操作 | 用法 |
|---|---|
| 鼠标点击 | 点击门、物件或NPC，角色靠近后交互。金圈通常表示尚可调查。 |
| Tab | 打开/关闭思维面板。单击卡片看全文，拖到槽位后点击“推理”。详情打开时先关闭详情。 |
| 推理结果页 | 回看已经得到的结论。重复正确组合不扣专注力、不重复升级。 |
| Q / E / W | 左转 / 右转 / 镜头回中。剧情和对决期间会锁定。 |
| M / Esc | 地图 / 暂停；阅读弹窗中Esc优先关闭阅读。 |
| 对峙准备 | 可Tab查线索，也可选“暂不对峙”继续调查。正式确认后不能撤退。 |

四声音初始都是1。物证共有58种，互斥选项决定一局拿不到全部58条。推理结论和物证计数分开；九组推理中只有“门禁＋染血纸条”首次成功额外给逻辑+1。

时间由剧情事件和首次进入地区推进，站着不动、现实等待、普通重复阅读不会自动到天亮。不要把无限喝酒当作推进时间的方法，喝酒每局只能一次。当前没有用于回滚不同结局的普通存档选择；想看另一个结局需要重新调查。

## 推荐路线：保留A/B/C/D四种选择

### 1. 红灯区小巷：拿警徽和纸条

1. 等开场结束，收集【警徽：编号NC-2077】和【染血纸条】。
2. 按Tab，单击纸条看全文；关闭详情，把纸条单独拖进任意推理槽，点击推理。
3. 得到“死者曾约你23:00见面”。另一槽留空即可；这一步不消耗专注力。
4. 从出口前往红灯区。

### 2. 红灯区：先拿共情，再拿逻辑和权威

首次加载完会自动与神秘女子交谈，结束前不能移动和旋转镜头。

| 人物/地点 | 推荐选择 | 作用 |
|---|---|---|
| 神秘女子 | “不好意思女士，我是不是吓到你了？” | 共情1→2；得到【我的焦虑】【她认识我】，保证之后能读自己的日记。 |
| 酒保 | “是吗，那昨晚我几点来的？” | 逻辑1→2，取得【酒吧时间线】。 |
| 电话亭 | “你是谁？” | 权威1→2，取得【匿名威胁】，时间推进到23:00。 |

女子交谈后靠近电话亭会有响铃提示，完成电话对白。酒吧和电话亭可前后调换；上述三个推荐选择不要换成其他分支。

无酒精饮料是酒保的另一个互斥选项，不是问完时间线还能追加购买。本路线不选它，以取得永久逻辑成长。若改选无酒精饮料，临时逻辑+1仅在红灯区有效，离开地区会消失。

完成后前往金融街。

### 3. 金融街案发公寓：门禁、记忆空白、日记、录音

进入死者公寓，按以下顺序调查：

1. 取得【门禁：22:45有人进入】，并收集弹孔、外卖、碎照片等可见金圈物件。**没有备用钥匙了，不用寻找。**
2. 检视尸体，选择 **“我真的不记得了……”**，取得【记忆空白】，疯狂1→2。这个分支是D结局必需的，不能事后回来补选。
3. 按Tab组合 **【门禁：22:45有人进入】＋【染血纸条】**，逻辑2→3。成功结论会存入结果页。
4. 与保安交谈，推荐选 **“那我问你，监控为什么被删了？”**，得到【保安被收买】【被删录像：23:00–23:30】，逻辑3→4。
5. 第一段结束后，再点同一个保安，选择 **“先找乞丐”**。这会开放乞丐的正式证词。不要误以为一次对话已经做完两段。
6. 点击卧室门打开，进去收集安眠药、风衣等线索。
7. 检查书桌日记，逻辑≥2即可读懂。读完得到【日记：死者被威胁】与【保险箱密码：2077】。
8. 点击保险箱，在密码面板输入 **2077**，取得【录音：风衣男威胁】，可阅读全文。

推荐额外推理：【保安被收买】＋【被删录像】。这组帮助理解案情，但不再加逻辑，也不增加物证条数。

“先找乞丐”和“封锁现场”是互斥选择。选封锁会获得指纹，但本路线为了拿乞丐目击，选择先找乞丐；通关不要求拿到所有互斥物证。

### 4. 公寓门口：第一次风衣男对决

从公寓出口返回金融街后，满足 **累计至少4条不同物证＋持有录音**，会进入对峙准备。按上述路线早已超过4条，不用专门计算点击次数。

准备好后确认，按这个顺序出牌：

| 当前证词 | 出牌 |
|---|---|
| “我昨晚根本没来过这里。监控完全可以证明。” | **保安被收买** |
| “就算监控没了，也没证据把我和这个案子连起来。” | **录音：风衣男威胁** |

成功获得【风衣男承认在场】和【掉落的钥匙】。注意第一句不要出门禁，当前版本它不是这一句的正确牌。

如果第一次出来没有录音，只会发生警告遭遇并损失10专注力。返回卧室开保险箱，再回来仍可进行正式对决。准备阶段也可以“暂不对峙”，调查后再回来。

### 5. 金融街补查：乞丐和咖啡馆

- 喷泉旁乞丐：选 **给钱**，取得【风衣男跑向工业区】，共情2→3。没有钱包系统，不需要先找钱。选不给钱会错失本段证词。
- 咖啡师：一定选 **“那张餐巾纸呢，你还有吗？”**，取得【餐巾纸：凶手是……】。

“餐巾纸笔记”与“餐巾纸：凶手是……”不是同一条。D结局需要后者；其他两个咖啡师选项不能替代。

### 6. 旧工业区：钥匙核对、仓库、地下室、天台

1. 调查铁门、车辙、涂鸦。
2. 拿着掉落钥匙检查铁门，会记录钥匙匹配结论；也可以在思维面板组合【掉落的钥匙】＋【铁门：被撬开】。铁门已经被撬开，钥匙不用于开启地下室或住宅门。
3. 仓库找瘦猴，选 **“我欠你多少？”**，逻辑4→5，取得【你曾用情报交易】。
4. 再点瘦猴进入下一段，推荐选 **“查风衣男”**，取得前警探档案，耗时15分钟。这个档案不是结局硬门槛，但可以参与新增推理。
5. 去地下室，收集血迹、工具、照片墙等线索。电脑要求逻辑≥3，本路线已有5，可以解密并读邮件，获得【你曾是卧底】【任务失败】。
6. 点击去天台的门，角色应沿外部楼梯上去。与狙击手交谈选 **“谁派你来的？”**，权威2→3，取得【警局高层介入】。
7. 前往住宅区。首次进入时间推进到03:30。

可以顺手做【前搭档合影】＋【风衣男档案】，以及【风衣男跑向工业区】＋【车辙】两组推理。

### 7. 住宅区：先自己家，出门找家属，再回家

1. 调查街道的信箱、路灯和猫。**信箱的【你的信：警告】是D结局必需品。** 路灯刻痕使疯狂2→3。
2. 找门牌 **NC-2077** 进入自己家。301和308打不开，305是死者家。
3. 首次回家先调查镜子、药瓶、开除通知和日记。镜子使疯狂3→4；日记要求共情≥2，本路线已有3。
4. 点击自家出口，会触发“出门前的念头”。选 **“去死者家问问家属”**，对话结束后实际回到街道。
5. 进入 **305**，与妻子交谈，推荐选 **“真的对不起，女士。我昨晚和他吵了什么？”**，共情3→4。
6. 第一段结束后，再点同一个妻子，选择 **“看遗物”**，耗时15分钟，取得 **【死者笔记：风衣男和警局高层有交易】**。这是A结局关键牌。
7. 返回 **NC-2077**。满足普通终章条件后，能看见坐着等待的风衣男。接近或点击他进入准备界面。

普通终章条件：**离开过自己家＋家中至少一条线索＋完成妻子的看/不看遗物选择＋累计至少10条物证**。仅去305但没完成第二段，不算完成家属调查。

“出门前的念头”另外两个选项：喝酒只允许一次（+60分钟、疯狂+1）；折返在≥10条时可以提前对峙。推荐路线不选折返，先拿完死者笔记。误入准备界面可选“暂不对峙”继续调查，不必重开。

## 最终对决前检查

按以上推荐路线、没有乱出牌或改选时，声音应为：

| 逻辑 | 共情 | 权威 | 疯狂 |
|---|---|---|---|
| 5 | 4 | 3 | 4 |

必须检查卡片是否实际拿到，而不只看名字相似的提示：

- 警徽。
- 录音：风衣男威胁。
- 餐巾纸：凶手是……。
- 记忆空白。
- 你的信：警告。
- 死者笔记：风衣男和警局高层有交易。

不要求58条全收齐，普通路线达到10条就够进入终章。确认开战前可以Tab查看、退出继续调查；正式开战后不能撤退。

## 最终对决与五种结局

### 推荐前两阶段出牌

1. 第一阶段“你怀疑他”：出 **录音**。
2. 第二阶段“他怀疑你”：出 **餐巾纸：凶手是……**，疯狂+2。本路线此时疯狂达到6。
3. 第三阶段按下表选择结局。

卡片不会因为出过而消耗，录音和餐巾纸在第三阶段仍能使用。

| 结局 | 第三阶段出牌 | 额外要求 |
|---|---|---|
| **A 完美真相** | 死者笔记 | 逻辑≥3；必须在妻子第二段选“看遗物”取得真正笔记。 |
| **B 正义执行** | 警徽 | 无额外声音门槛。 |
| **C 都市规则** | 录音：风衣男威胁 | 权威≥2、疯狂≥2。 |
| **D 你是凶手** | 餐巾纸：凶手是…… | 疯狂≥3，且持有【你的信：警告】和【记忆空白】。 |
| **E 悬案** | 最终对决失败 | 最终对决累计3次失误/断链。例如第一阶段连续出无关的【弹孔】。 |

E还有“剧情时间达到06:00、尚未正式开始最终对决”的入口，但当前时间按事件推进，不要原地等，也不要靠重复喝酒；想稳定查看E，用最终对决失败分支最直接。金融街中途对决失败不等于直接进入E。正式开始最终对决后不会被时钟事件打断。

### 若走了其他路线，可用的替代牌

| 阶段 | 可正确推进的替代牌 | 效果 |
|---|---|---|
| 第一阶段 | 门禁：22:45 | 疯狂+1 |
| 第一阶段 | 你的日记：怀疑搭档 | 共情+1 |
| 第二阶段 | 你的信：警告 | 共情+2 |
| 第二阶段 | 镜子：你脸上有伤 | 逻辑+1 |

“追问”免费，可读提示；错误牌扣专注力并累计失误。没有可推进的牌时，允许跳过的回合会显示“跳过本轮”，但也计一次断链并扣专注力，不是免费跳关。

第三阶段门槛不足的结局牌不会自动给另一个结局。不要把此前旧版的“34条线索、四声音全部3”等条件套到当前版本。

## 当前全部9组推理

卡片顺序不限；单卡教学只放一张。除了门禁＋纸条首次逻辑+1，其余不提供额外等级奖励，也不增加物证总数。

| 放入槽位的线索 | 结论用途 |
|---|---|
| 染血纸条（单卡） | 23:00约会时间，序章教学。 |
| 门禁：22:45＋染血纸条 | 约定前有人刷你的警徽进入；首次逻辑+1。 |
| 掉落的钥匙＋铁门：被撬开 | 风衣男持有匹配钥匙，不等于证明他撬门。 |
| 保安被收买＋被删录像 | 监控空白是人为制造，不能当作没到场的证明。 |
| 风衣男是你的前搭档＋风衣男档案：前警探 | 核对过去的关系与职业。 |
| 你曾是卧底＋警局开除通知 | 联系三年前任务与开除经历。 |
| 安眠药＋安眠药：已空 | 比对两个住处的相同药物，不直接断言谁服用了药。 |
| 风衣男跑向工业区＋车辙：摩托车 | 确定继续调查仓库的方向，不直接认定车辆归属。 |
| 你的信：警告＋风衣男是你的前搭档 | 身份可验证，但“背叛”指控仍需其他证据。 |

## 常见卡点

- **日记读不懂/电脑不能用**：分别检查逻辑2/逻辑3；酒吧问时间线与门禁＋纸条是稳定永久成长，冷静是地区内临时加成。
- **乞丐只说省略号**：回去完成保安第二段，选“先找乞丐”；不是看到乞丐就已经解锁证词。
- **拿到“他一直留着笔记”，却不能进A**：它只是提示。再与妻子交谈并选“看遗物”。
- **拿了餐巾纸笔记却进不了D**：咖啡师要选索要那张餐巾纸，取得标题含“凶手是……”的卡。
- **终章人物没出现**：先查自己家、完成妻子第二段、离家后返回，并满足10条。主动折返是另一条提前入口。
- **想离开对决继续调查**：仅准备阶段可拒绝。正式确认后只能完成对决或失败。
- **想体验所有结局**：本路线保留四种成功结局选择，但一局只能选一种；重新调查后改变最后出牌即可。

本文是基于当前实现的可操作路线与条件核对，不声称已用人工鼠标从头完成五次独立通关。游戏当前仍使用灰盒场景和基础演出，物件外观可能与描述不完全一致。
