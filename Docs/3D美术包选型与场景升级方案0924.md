# 3D美术包选型与场景升级方案

本轮仅盘点、读取Prefab/材质/动画配置、保存资产预览与编写方案；没有改动游戏场景、材质或导航。不以导入时间推断哪些包是本次新加，以下按当前项目实际存在的四组资源评估。

## 结论

可以明显改善当前灰盒，但不能直接得到与GROK插画同等写实的3D画面。四组资源以低多边形风格为主；建议采用“具象低多边形3D＋写实叙事插画”，统一人物服装、主色、年代和灯光，避免把画面描述成已经完全写实。

以Poly Universal Pack的City/Modular/Props作为近景环境主库，LowPolyMegapolis作为建筑外壳与远景补充；POLYGON city pack谨慎补少量单件；Animated People提供骨骼人物和动作。不要把三个包各自的道路和建筑整套混排。

## 首先解决渲染兼容

项目当前使用URP。实查：

- Universal Pack主要材质为URP/Lit（93）、SpeedTree7（4）、URP粒子Unlit（3），另有程序天空。电话亭/集装箱预览正常。
- 两个城市包的建筑样本为Standard，Unity资产预览呈粉色。
- Animated People样本实际引用 `Assets/polyperfect/Common/Materials/atlas-LPAP.mat`，Shader为 `Standard (Specular setup)`；包内另有URP材质并不意味着这些Prefab已经正确引用。人物样本预览粉色。

实施时复制选中材质到项目自有 `Assets/Art/Materials/CityNoir/`，按对应工作流转换到URP并保留贴图/透明/法线/高光。对Specular流程要保留高光贴图含义，不能只换shader名称。不要全项目一键转换，不要改供应商原文件。先确认玻璃、窗户和霓虹正常，再评价造型颜色。

## 人物替换方法

保留DetectivePlayer/NPC原来的逻辑根节点、交互ID、Collider、导航代理与剧情组件，只替换Model子节点。人物统一到约1.8米尺度，脚底归零，朝向统一。

只复用包的Humanoid Avatar和适用动画，自建精简Animator：Idle、Walk、Turn/Talk、Sit/Stand、必要剧情动作。包控制器带攻击/死亡/僵尸等状态，不能直接接管游戏。移动动画优先in-place，由现有NavMesh驱动；root motion关闭，避免位移重复。

已发现Common_Walk、Walk_InPlace_Female、Walk_Male、Idle_Generic、Idle_HardDay、Idle_Waving等动作；未确认合适坐姿或“起身”成套动画，因此终章坐姿和开场起身必须单独验收，不写成现成可用。

头像与3D保持服装和轮廓对应：主角棕色外套/帽子，风衣男深色无帽；女子浅色雨衣，保安深蓝制服，乞丐毯子，咖啡师棕围裙。机械义眼、透明伞、帽子和长风衣下摆属于少量定制件，不混用战士/奇幻角色凑数。

## 技术落实约定

1. 建立项目自有Prefab Variants和材质，不破坏供应商目录，便于更新/回退。
2. `LogicRoot / Visual / InteractionAnchor / NavigationProxy` 分离。替换视觉不覆盖脚本引用、不改线索ID、不重建整张已调好的场景。
3. 选定物体先核对Bounds、正面、支点、门缝、玻璃；统一等比缩放，不把建筑拉扁硬塞。
4. 导入碰撞体只作参考，禁止和原逻辑碰撞/导航禁行区重叠叠加。小装饰不参加导航；桌椅按完整占地禁行；楼梯保留专用可行走坡面；门保留真正入口高度判断。
5. 建筑面向镜头的一侧拆分/隐藏或使用现有遮挡淡出，不让完整屋顶把俯视室内盖住。
6. 统一中性偏暗底色、蓝灰环境光、暖金局部灯，克制霓虹；提高湿地反射但不把每个物体做成镜子。材质调整不能把低多边形模型变成写实模型。
7. 样本未发现LODGroup；大楼/车辆先按远近分层，是否补LOD/合批以实际Profiler为准。避免把6492个Prefab全部纳入场景或Resources。

## 建议实施顺序与验收

### 第1批：技术和风格样板
- 修复选中城市/人物材质的URP兼容。
- 红灯区电话亭周围一段街景＋咖啡馆一间室内＋主角和风衣男两个角色。
- 交付白天中性光检查图、正常夜景GameView图、旋转镜头截图和一次完整进出/对话流程。
- 确认色彩、尺寸和“低多边形3D＋写实插画”的组合可接受后扩展，不先替换全城。

### 第2批：室外识别度
小巷→红灯区→金融街→工业区→住宅区。先大轮廓和道路层级，再中型地标，最后小物；每条主通路保持清楚，不靠到处加箱子制造丰富度。

### 第3批：室内与人物
咖啡馆/酒吧→案发公寓→仓库/地下室→两间住宅→天台。同步替换NPC外观与行走，但不修改剧情规则。

### 第4批：统一灯光与收尾
调整材质、灯光、雾、反射、遮挡、音效；补专用小件和已确认动画缺口。

每批必须核对：进门出生点、点击门自动接近、NPC不穿柜台、上下楼不瞬移、家具不可踩、桌面/墙面金圈正确、收集后提示消失、镜头Q/E各方向可读、返回场景人物不重复。编译/NavMesh通过不能代替这些实机检查。

## 当前不建议做

- 三套道路与建筑随机混用，或将整个Demo场景搬进游戏。
- 直接把Standard材质资源当作URP已适配。
- 为了用包的模型改变已有线索位置、入口关系和剧本门槛。
- 宣称这些包已覆盖写实人物、完整室内和全部剧情动画。

推荐先落第1批，预估首轮精选20—30个Prefab即可明显改善，不需要一口气替换所有场景。
