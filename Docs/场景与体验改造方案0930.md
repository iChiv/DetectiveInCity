## P0-1 门标签系统性不可读（13/13 场景全中招）

**审计结论**：标签挂在门顶上方约 y≈4.1，50° 俯视下永远在屏幕顶缘外；fontSize 8×0.55 在 7m 外不可读；走近又溢出屏幕；东西墙的门标签朝向不正对相机。

**方案**：
1. 标签从门顶降到**门楣高度（y≈2.3）**，即玩家视线层；
2. 门口地面加**发光门槛条**（金色/青色光带，贴地 y=0.02，宽同门洞）——远看认光带，近看读字；
3. 标签改为**距离淡入**：玩家 10m 内淡入、6m 内全亮，远了淡出（DetectiveDoorTeleport 每帧算距离控 alpha，成本可忽略）；
4. 字不再随墙体朝向固定，保持 billboard 对相机。

涉及：`DetectiveRegionBuilder.CreateDoor`、`DetectiveDoorTeleport.cs`。

## P0-2 线索收集没有游戏内反馈

**现状**：收集线索只 Debug.Log 到 console（`TestInteractable.cs:173`），`OnClueCollected` 事件没有任何订阅者。

**方案**：新建 `DetectiveClueToastListener`（挂 Systems）：订阅 `DetectiveGameState.OnClueCollected` → 查 `DetectiveClueCatalog` 拿标题 → `DetectiveToastUI.Instance.Show("获得线索【xxx】")`。声音升级也加 toast（"逻辑提升了"）。Toast UI 现成，改动约 30 行。

## P0-3 涂鸦等"看不见的内容" + 相机旋转

**审计结论**：涂鸦朝向其实没错（面朝北=朝相机），问题是它在 D3 南墙暗处、玩家动线背后、被集装箱遮挡。同类：天台天际线在玩家背后、狙击手黑胶囊融入黑屋面。

**方案分两部分**：

a) **内容修正**：涂鸦移到玩家必经视线内（D3 入口铁门旁或西墙）；Poster_D（金融街悬空）、Poster_E（工业区悬空）、PipeRun（穿模埋进厂房）修复；天台狙击手加轮廓光/聚光灯，天际线楼群移到北侧可见处。

b) **相机旋转功能（评估结论：建议做，成本低收益大）**：
- 现状：`DetectiveFollowCamera` 已有 `cameraYawDegrees`（默认 35°）字段和滚轮缩放，旋转只差输入绑定。
- 实现：滚轮 = 围绕玩家平滑旋转（改 cameraYawDegrees），**鼠标中键点击 = 回弹默认角度**；缩放改到 `+`/`-` 键（或先去掉，原型阶段不需要）。
- 影响面评估：点击移动走相机射线，不受影响；门/线索标签本来就 billboard 对相机；遮挡淡出 `DetectiveCameraOcclusion` 基于相机位置自动适配；地图是独立 UI 不受影响。唯一注意点：旋转后"屏幕方向=世界方向"的直觉变弱，靠门口光带+标签+地图兜底。
- 工作量：改 `DetectiveFollowCamera` 一个文件，约 40 行。

## P1-2 路灯刻痕呈现

**现状**：悬空米色块 + 世界文字（玩家看到的"路灯上的字"）。这是剧情线索【路灯：七道刻痕】（疯狂+1），内容要保留，呈现重做：刻痕做成贴在灯杆上的深色横条小块组（5-7 道），标签改为与其他线索一致的贴地金色光圈，点击检视时出描述文字。

## P1-3 NPC 离场移动

**现状**：对话完成后 NPC 直接 SetActive(false) 瞬消。

**方案**：新增 `DetectiveNpcWalker` 组件——完成 flag 设置后，NPC 用 NavMeshAgent 走向预设离场点（门口/场景边缘），到位后淡出再禁用。`CreateNpcGate` 加 walkAwayPoint 参数。涉及：神秘女子（走向街角）、狙击手（退到天台边缘）、风衣男（对决后逃走）、乞丐（可选不动）。注意：室内 NPC 的离场点要在本场景 NavMesh 内。

## P1-6 循环可测性（debug 工具）

**问题**：现在玩不完整个循环，结局没法测。

**方案**：新增 `Detective/Debug/` 编辑器菜单（播放中可用）：
- 跳转到指定区域（调 `DetectiveRegionLoader.LoadRegion`）
- 发放指定线索包（如"最终对决全套"）
- 设置声音等级/专注力/时间
- 直接触发结局 A~E（SetFlag ending_choice_x）
约 100 行编辑器代码，之后每轮改动都能快速验证结局链路。
